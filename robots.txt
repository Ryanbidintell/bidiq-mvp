# IMPORTANT: robots.txt groups are NOT additive. A crawler that matches its own
# User-agent group obeys ONLY that group and ignores "User-agent: *" entirely.
# That means every named group below must repeat the Disallow rules — if you add
# a bare "User-agent: GPTBot / Allow: /" group, that bot loses the admin-page
# protections. Keep the Disallow block in sync across all groups.
